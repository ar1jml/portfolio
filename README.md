# Arafat J. Portfolio

Personal portfolio website for Arafat J., a software developer learning and building with backend development, APIs, databases, DevOps, cloud technologies, and artificial intelligence.

## Features

- Responsive portfolio layout
- Light and dark theme switcher
- Dotted background inspired by the design reference
- Skills and tools overview
- Education and certification sections
- Smart Price Monitoring Dashboard project
- Blog section focused on learning software engineering and AI
- Contact links for email, phone, LinkedIn, GitHub, and Telegram
- Downloadable resume text file

## Run Locally

No build tools are required. Open `index.html` directly in a browser, or start a local server from the project directory:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.
